- Tap the fullscreen book's page number to open a touch-friendly page slider. Drag to preview a page, then release to open it, without an input keyboard.
- Tap the slider track to choose a page, or use the existing previous/next-page buttons for small steps. Unit selection, CD speed and reading position are preserved.
- Jumping back to a page after using the page arrows now always displays the selected book page.
- All existing learning progress, book pages and offline media are preserved.
